# 🎯 Estrategia de Landing SaaS B2B para Entrenadores

## Público Objetivo

**Entrenadores personales y coaches fitness** que:
- Gestionan 5-50+ clientes simultáneamente
- Cobran por planes/membresías
- Quieren escalar sin perder control
- Buscan profesionalismo y eficiencia

### Jobs to be Done (JTBD)

El cliente **NO compra software**, compra:
1. ⏱️ **Tiempo** - Menos horas en tareas administrativas
2. 📊 **Orden** - Sistema centralizado vs. caos de herramientas
3. 💼 **Profesionalismo** - Imagen premium frente a clientes
4. 💰 **Escalabilidad** - Más clientes sin más fricción
5. 🧠 **Claridad mental** - Menos estrés operativo

---

## Propuesta de Valor Única (UVP)

> **Convierte tu conocimiento en un sistema escalable**  
> Gestiona clientes, sesiones y pagos desde un solo lugar, sin fricción técnica.

### Diferenciadores clave:
- **Outcome-focused**: Vendemos resultados, no features
- **B2B clarity**: Lenguaje profesional, no hype
- **ROI-driven**: Enfoque en ahorro de tiempo y aumento de ingresos
- **No-tech-barrier**: "Hecho para entrenadores, no para developers"

## Métricas de Éxito (MVP)

### Conversion Funnel
1. **Landing views** → Baseline
2. **CTA clicks** → CTR objetivo: 5-8%
3. **Form starts** → 60% de CTA clicks
4. **Form completions** → 70% de starts
5. **Activations** → 50% de completions

### KPIs Clave
- **Conversion rate**: 2-4% (landing → signup)
- **Lead rate**: 8-12% (landing → lead capture)
- **CAC estimado**: $20-50 (con ads)
- **Time to signup**: < 3 min
- **Bounce rate**: < 50%

### A/B Testing Roadmap (Fase 2)
1. **Hero headline**: Beneficio vs. Característica
2. **CTA copy**: "Prueba gratis" vs. "Empieza ahora"
3. **Pricing display**: Mensual vs. Anual destacado
4. **Social proof**: Testimonios vs. Métricas

## Tracking y Compliance

### Eventos a Trackear
```javascript
// Hero CTA
track('cta_click', { location: 'hero', action: 'signup' })

// Pricing CTA
track('pricing_cta_click', { plan: 'pro', period: 'monthly' })

// Form interactions
track('form_start', { form_id: 'signup' })
track('form_field_complete', { field: 'email' })
track('form_submit', { form_id: 'signup' })

// Scroll depth
track('scroll_depth', { percentage: 25 })
```

### GDPR Compliance
- **Cookie consent**: Banner al entrar
- **Privacy policy**: Link en footer
- **Terms of service**: Link en footer
- **Data export**: Funcionalidad en cuenta
- **Right to deletion**: Proceso documentado

## Restricciones de Diseño

### ✅ MANTENER (Identidad existente)
- **Paleta de colores**: 
  - Primary: `#0B0B0F` (bg)
  - Accent: `#5227FF` (purple)
  - Text: Escala de grises (`#FFFFFF` → `#646478`)
- **Tipografía**: 
  - Sans: `Inter`
  - Mono: `JetBrains Mono`
- **Spacing system**: 8px base
- **Border radius**: Consistente con design system

### 🔄 CAMBIAR (Enfoque y estructura)
- **Layout**: De técnico/developer a B2B/business
- **Copy**: De features a outcomes
- **Jerarquía**: De producto a beneficios
- **CTAs**: De "Empezar a crear" a "Prueba gratis"
- **Secciones**: De "Cómo funciona" a "Qué logras"
